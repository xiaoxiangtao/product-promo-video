# 声音

## 1. 管线

```
synth_music.py  → music.wav（配乐 + 事件音效，峰值 -1 dBFS）
add_voice.py    → music_voice.wav（可选：旁白 / 场景里的人声，自动压低配乐）
finalize.py mux → 成片（loudnorm 到 -16 LUFS，48 kHz AAC 256k）
```

响度：网页/社媒 -16 LUFS（偏安静、耐听），需要更响时 -14。用 `finalize.py loud <文件>` 量。

## 2. synth_music.py 结构

- **和弦**：`#timeline.music.chords` 每小节一个，按全局小节号循环；`bass` 是对应根音。默认 D 大调 Dmaj7–Bm7–Gmaj7–A，明亮、不甜腻。换调：所有 MIDI 号整体加减。
- **铺底**（pad）：每小节一个低通和弦，全程不断。
- **动机**（MOTIF）：两小节一循环的 16 分音符型，音高取和弦内音序号，所以换和弦自动跟着变。energy ≤1 只留骨架音、用拇指琴音色；≥2 用马林巴全奏；≥3 高八度。
- **energy**（场景属性）：0–1 安静（片头片尾），2 加贝斯和沙锤（功能段），3 加底鼓和响指（高潮、总结）。
- **场景交界**：一记三音上行扫弦。
- **结尾**：最后一小节只留扫弦 + 主和弦长音 + 低音淡出。
- **事件音效**：`click` 鼠标、`typing` 打字（按 `n`、`dur` 分布）、`ding` 出结果、`pop` 贴纸/卡片、`whoosh` 上扬（在事件点前抵达）。加新类型：写一个 `sfx_xxx(t0, e)` 函数并登记到 `SFX` 字典，时间轴里就能用 `"type": "xxx"`。
- `--stems` 另存各声部，方便判断哪一层太响。

## 3. 编曲原则（来自 v3→v6j 的多轮试听）

用户的反馈很少直接说"哪里不对"，通常是"不连贯""平庸""像乱弹""结尾乱"。对应的原因：

| 反馈 | 真正原因 | 做法 |
|---|---|---|
| 不连贯 | 段落之间有空洞（某段只剩一两个声部、最后一个旋律音被删）、和弦循环被插入段打断 | 铺底全程不断；插入段落时补整数个和弦循环（例如插 4 小节而不是 2 小节）；检查 <-40 dB 窗口为 0 |
| 平庸 | 为了连贯把有特点的旋律换成了安全的编排 | 保留用户喜欢的那版的调子和音色，只修衔接，不重编 |
| 像乱弹 | 在空隙里随便加和弦音 | 填充音要有方向（比刚弹的旋律音高一级、一路往上走），不随机 |
| 节奏感差 | 回声/附点音抢了下一小节的重拍 | 填充只放在正拍，不越过小节线 |
| 结尾乱 | 尾巴上堆了多个和弦和不规整的旋律 | 结尾只留一条线：扫弦 → 一个记忆点（如产品的声音）→ 主和弦长音 |
| 太广告 | 四踩底鼓、侧链泵感、冲击音效 | 去掉；用木质/拨弦音色和轻律动 |

其他经验：

- 用户喜欢的某个小元素（例如"扫弦"）可以复用成全片的过渡记号，一致性会提升整体感。
- 早期版本里被认可的细节（键盘声、鼠标点击声、产品自己的声音）后来如果丢了，用户会想要回来——改版时列清单检查哪些音效还在。
- 产品若有"声音形象"（吉祥物叫声、提示音），在片头出场和片尾各放一次，与画面同拍。
- 每轮改配乐都保留旧版脚本和 wav，方便用户 A/B 对比；用户常常要回到前几版。

## 4. 旁白与场景人声（add_voice.py）

- 台词写进时间轴 `voice`：`{"at": [小节,拍], "to": [小节,拍], "text": "..."}`。画面字幕可以读同一份数组，保证对齐。
- `--style clean`：干净旁白（高通去低频）。`--style speaker`：带通 + 轻饱和 + 短房间混响，模拟"屏幕里外放的录音"，适合演示字幕/会议类功能时做环境声，配乐同时压低 5 dB 左右。
- macOS `say` 适合做场景里的环境人声；正式旁白建议用户提供录音或高质量 TTS（`--tts files`，每句 `file` 字段指定 wav）。
- `say` 基本不响应语速参数，句子太长时脚本用 `atempo` 最多压到 1.25 倍；仍超出就缩短台词或加长窗口。
- 人声起止：比字幕早约 0.1 s 开口；需要在某个动作处淡出时，让当前这句说完再淡（1.5–2 s），突然掐断很明显。

## 5. 用现成音乐

用户有授权音乐时：量出 BPM 和第一拍的偏移，按它写时间轴（偏移可以让所有 `at` 加一个常数）。然后 `synth_music.py promo.html sfx.wav --sfx-only` 只生成音效层，用 ffmpeg `amix` 把音乐和音效层混在一起（音效约比音乐低 6 dB），再 `finalize.py mux`。卡点仍然由时间轴保证。
