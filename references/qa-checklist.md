# 审片与交付清单

## 审片（每次交片前）

先出总览图（`finalize.py sheet 成片 out.jpg --every 2`），再对每段的关键时刻出全尺寸静帧逐张看。

**内容**
- [ ] 每个说法、数字都能在 storyboard.md 的出处表里找到
- [ ] 界面上的按钮、文案、状态流转和当前版本的真实产品一致
- [ ] 演示内容是产品真实会输出的格式
- [ ] 没有未经同意的个人信息（姓名、邮箱、仓库地址里的用户名、照片）

**画面**
- [ ] 文字没有被窗口、卡片、手绘标注遮挡；副标题没有贴到窗口
- [ ] 没有溢出、截断、意外折行（英文版重点查）
- [ ] 推镜放大时没有顶到标题区
- [ ] 每段至少有一个动作，没有超过约 2 秒的静止画面
- [ ] 段落交界没有明显的空白帧（窗口已退、下一段还没进）
- [ ] 光标的每次点击都落在目标上，涟漪与音效同时出现
- [ ] 位图素材没有发糊

**声音**
- [ ] 每个点击、出现都有对应音效，且对齐（抽几处静帧时间核对）
- [ ] 配乐全程无空洞（synth_music 日志的 <-40 dB 窗口数为 0）
- [ ] 结尾干净，最后 0.5 s 画面和声音一起淡出
- [ ] 成片响度在目标 ±1 LU 内（`finalize.py loud`）

**技术**
- [ ] 1920×1080、30 fps、yuv420p、faststart（能在浏览器和手机直接播）
- [ ] 渲染日志没有页面报错

## 交付

- [ ] 主版本：`<产品>-promo-<秒>s-v<N>.mp4`
- [ ] 其他语言版：`-en.mp4`，逐段静帧检查过排版
- [ ] 脱敏版（如需要）：单独子文件夹
- [ ] 网页版：`finalize.py web`，体积 ≤ 5 MB 左右
- [ ] 封面：片头标题完整出现的那一帧，1280 宽
- [ ] storyboard.md 记录了本版的反馈与改动，以及复现命令
- [ ] 旧版本整理：列清单给用户确认后再归档/删除
