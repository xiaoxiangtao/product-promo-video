# 视觉与动效

## 1. 两种画面状态

| | 片头 / 规格页 / 片尾 | 功能段 / 总结 |
|---|---|---|
| 风格 | **由用户决定**（见第 2 节的方向），模板自带剪纸拼贴示例 | 固定：中性浅灰白渐变 + 极淡的品牌色光斑 |
| 主体 | 产品名 + 一句价值主张 + 产品主视觉 | 左上标题区 + 右侧产品窗口 |
| 颜色 | 品牌主色为主，和功能段形成明显对比 | 背景和卡片不上色，彩色只给标题关键词和手绘强调 |

两种状态之间用整屏切换过渡（模板是整屏上推 translateY ±1180 px，0.45 s 缓入缓出），换风格时可以改成淡入淡出、缩放等。

## 2. 片头片尾风格方向

给用户出试稿时，从下面挑 2–3 个差别明显的方向，或按用户的参考来：

| 方向 | 适合 | 实现要点 |
|---|---|---|
| 极简大字 | 工具、开发者产品、想显得专业克制 | 纯色或深色底，超大字号产品名逐词上浮，留白多；几乎不用装饰 |
| 产品主视觉 | 有好看的界面、图标或硬件外观 | 产品截图/图标居中缓慢推近，光影渐变背景，名字在下方淡入 |
| 渐变光效 | 偏科技、AI 类产品 | 大面积柔和渐变光斑缓慢流动（CSS radial-gradient 随 t 移动），标题玻璃质感 |
| 剪纸拼贴（模板自带） | 偏生活、学习、有亲和力的产品 | 撕边纸 + 两层阴影 + 胶带，入场按 12 fps 定格，见第 5 节 |
| 手绘 / 插画 | 有吉祥物或插画品牌形象 | SVG 线条按 stroke-dashoffset 描出，配品牌插画 |
| 界面拼贴 | 功能多、想一上来就展示全貌 | 多个界面卡片从四周飞入铺满再收拢成产品名 |

不管哪种方向：片头 ≤ 2 小节，产品名要在前 3 秒内清楚出现；片尾与片头同风格、同构图，只换文案和细节，形成首尾呼应。

## 3. 版式（1920×1080）

- 标题区：左 110 px、上 120 px、宽 700–760 px。主标题 74 px / 700 字重 / 字距 -1.5 px；副标题 28 px / 500 / 灰 `#6e6e73`，与主标题间距 40 px（太近会挤，且要给手绘强调留位置）。
- 产品窗口：右侧，约 x 960–1800、y 190–890。窗口圆角 20、短而柔的阴影（`0 18px 40px rgba(30,20,60,.12)`）。
- 产品界面按真实尺寸 × 1.4–1.6 放大；太高放不下时按 `min(1.6, 可用高度 / 内容高度)` 自动缩。
- 主角（产品图标、吉祥物、硬件照片）可以压住标题右端或居中偏右，大胆一点，让它成为画面重心。
- 英文版标题区通常要单独加宽或减小字号。

## 4. 颜色

- 渐变关键词色（模板 `.g1–.g4`）：橙→粉、粉→紫、蓝→青、墨绿→青蓝。每段一种，不要一段里用两种。
- 避免"塑料感"的纯绿、纯红；需要绿色时用墨绿系（`#0f8f6f → #2c7da0`）。
- 删除/危险操作用 `#e5484d` 系，只出现在相应交互上。
- 深色模式不需要考虑——视频是固定画面。

## 5. 剪纸拼贴的做法（模板自带的片头片尾示例）

用户选了这个方向时参考；选了别的方向就跳过本节。

- **撕边**：SVG `feTurbulence + feDisplacementMap`（scale 8–12）只作用在纸片的背景层（模板里 `.paper>i`），不要作用在含文字的元素上，否则文字会一起被扭曲。
- **阴影**：两层 `drop-shadow`——贴合的短影 + 悬空的柔影，光向统一（从左上来）。`box-shadow` 不跟随撕边形状，不要用。
- **颗粒**：全屏 SVG 噪点，拼贴段 0.10，功能段 0.05。
- **胶带**：半透明米白矩形，斜贴在纸条一角。
- **字母纸片**：每个字母一张纸，角度在 ±6° 内交替，依次 0.1 s "重贴"（slam）。
- 所有元素都用 SVG/CSS 生成，不依赖外部素材，这样改颜色和尺寸都是一行代码。

## 6. 动效词汇表

模板里的缓动：`E`（ease-out cubic）、`EI`（ease-in-out）、`eb`（回弹），`win(t,a,b,c,d)` 表示 a→b 渐入、c→d 渐出。

| 动效 | 用途 | 参数 |
|---|---|---|
| `reveal` 上浮 + 去模糊 | 标题、副标题、列表行 | 0.45 s，位移 18–26 px，模糊 8–12 px；副标题比主标题晚 1 拍 |
| `pop` 回弹放大 | 卡片、结果、图标出现 | 0.3–0.4 s，从 1.25–1.35 倍回到 1 |
| 盖章（大倍数 pop） | 一个关键数字 | 从 1.6 倍落下，0.3 s，配 whoosh |
| `stick` / `slam` | 剪纸元素贴上 / 用力拍上（剪纸风格） | 0.25–0.3 s，带 8–14° 旋转回正，12 fps 量化 |
| `rise` | 剪纸段里的文字（剪纸风格） | 0.35 s 上浮，12 fps 量化 |
| 窗口进出 | 产品窗口 | 进 0.5 s（上移 40 px + 0.98→1 缩放），出 0.4 s |
| 推镜 | 要看清的小细节（选中的词、按钮） | 放大 1.06–1.16 倍，以目标为原点，0.5 s；放大时同时下移，避免顶到标题 |
| 光标移动 | 交互演示 | 在到达点击时间前 ≤0.6 s 开始移动（先停留再快速移过去，像真人） |
| 点击 | 交互演示 | 涟漪 0.45 s 扩散淡出 + 光标缩到 0.85 一下 + 按钮按下 0.15 s |
| 逐字输入 | 输入框 | 字符按事件 `dur` 均匀出现，带闪烁光标；音效按 `n` 均匀打字声 |
| 流式回复 | AI 输出 | 0.9–3 s 逐字出现，结束后出处/状态行再淡入 |
| 手绘强调 | 标题关键词 | 标题出现半拍后用 `stroke-dashoffset` 描出 0.45 s |

**手绘强调的语义**（统一后观众能读懂）：波浪线 = 动作/过程；圈线 = 成果；马克笔 = 重点。一段只用一种。

**不要做的**：画面随鼓点整体抖动或缩放；放射光、粒子爆炸；同时出现超过 2 处手绘标注；与功能无关的装饰贴纸（星星、音符等通用元素会显得突兀，要换成产品自己的符号）。

## 7. 复刻真实界面

1. 找到界面源码（SwiftUI/AppKit/React/CSS），读出真实的宽度、圆角、字号、颜色、间距、按钮文字、状态文案。没有源码就用 2× 截图量。
2. 在页面里用 HTML/CSS 按 pt→px 1:1 写出来，再整体乘放大倍数。
3. 状态流转按真实逻辑来：真实产品里要点两下才删，视频里就点两下；真实产品里收起后字号不变，视频里就不要放大字号。
4. 产品更新界面后，视频要跟着同步。
5. 位图素材（图标、照片、动画帧）按最终显示尺寸的 1–2 倍导出；放大超过 1.3 倍就会发软。

## 8. 加一个新部件的写法

```js
function myPart(t){
  const s=S.f2, el=$('mypart');
  el.style.opacity = win(t, s.t0+0.2, s.t0+0.6, s.t1-0.3, s.t1);   // 本段内渐入渐出
  pop(el, t, T.myEvent, 0.35);                                       // 在事件点弹出
}
// 然后在 render(t) 里调用 myPart(t)
```

原则：只读 t 和常量，不读上一帧的状态（不能有 `x += ...` 这样的累积），这样任意一帧可以单独渲染，`--from/--to` 局部重渲也不会出错。
